# Vazirmatn Font Files

Place the following Vazirmatn TTF font files in this directory:

- `Vazirmatn-Regular.ttf` (weight: 400)
- `Vazirmatn-Medium.ttf` (weight: 500)
- `Vazirmatn-Bold.ttf` (weight: 700)

## Download
Official Vazirmatn fonts can be downloaded from:
- GitHub: https://github.com/rastikerdar/vazirmatn/releases
- Or: https://github.com/rastikerdar/vazir-font

## Usage
These fonts are registered in `pubspec.yaml` under the family name `Vazirmatn`.
Use in Flutter with: `TextStyle(fontFamily: 'Vazirmatn')`
