# Inter Font Files

Place the following Inter TTF font files in this directory:

- `Inter-Regular.ttf` (weight: 400)
- `Inter-Medium.ttf` (weight: 500)
- `Inter-SemiBold.ttf` (weight: 600)
- `Inter-Bold.ttf` (weight: 700)

## Download
Official Inter fonts can be downloaded from:
- GitHub: https://github.com/rsms/inter/releases
- Website: https://rsms.me/inter/

## Usage
These fonts are registered in `pubspec.yaml` under the family name `Inter`.
Use in Flutter with: `TextStyle(fontFamily: 'Inter')`

## Why Inter?
Inter is a modern, sleek, and premium typeface designed for UI interfaces.
It features:
- Tall x-height for better readability at small sizes
- Variable font support
- Carefully crafted for screen rendering
- Used by Linear, Raycast, Vercel, GitHub, and other premium products
